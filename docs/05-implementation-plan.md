# 05 · 已批准实施方案与当前实现状态

更新时间：2026-10-16

## 1. 当前范围

本阶段只做“图片转拼豆图纸”：上传、裁剪、参数设置、浏览器本地转换、预览、基础微调、色号/用量/备料清单、PNG/PDF/CSV/JSON导出和本机草稿。

暂不开发：找图、社区、登录、商城、实时商品库存、自动下单、库存配色、AI重绘、自动抠图、多图层、3D。

## 2. 已选技术

- React 19 + TypeScript + Vite。
- CSS 变量和响应式 CSS；当前界面使用已确定的暖白、青绿、浅橙视觉基线。
- Zustand：作品和编辑状态。
- 原生 Canvas 2D：图纸预览、网格、色号和单格命中。
- Web Worker：转换计算和任务隔离。
- IndexedDB/Dexie：最近作品与恢复点。
- Zod：项目 JSON 导入校验。
- pdf-lib + fontkit + SIL OFL 授权的 Noto Sans CJK SC：中文 PDF。
- Vitest：核心和导出数据测试；Playwright 预留浏览器流程测试。

没有服务端；基础图片转换不上传图片。

## 3. 原版算法基线（保留对照，不代表质量合格）

2026-10-16 用户实测指出衣物碎点、脸部断层和小尺寸五官丢失。以下v1仍可运行以便同条件对照，但不能以测试通过代表视觉效果合格。当前调整为可选的区域连贯实验路径，研究及实验记录见 [算法研究与对照](06-algorithm-research.md)。

`linear-area-lab-kmeans12-ciede2000-v1`：

1. 将上传图片降采样到最长边不超过1600px用于本机处理，并检查文件大小/像素上限。
2. 照片/插画按目标格覆盖的原图区域做面积加权采样；在线性光空间处理透明合成。像素画模式使用最近邻采样。
3. 透明格与白色豆子独立表示；半透明按设置的衬底合成。
4. 用确定性、最远点初始化的加权 Lab 聚类，最多12轮；聚类数量不超过用户的颜色预算，实际颜色最多32色。
5. 聚类中心用 CIEDE2000 匹配到实际色卡候选；每个格子再映射到选中的色卡子集。启用抖动时使用固定 Floyd–Steinberg 分配，去杂点为邻域规则。
6. 统计永远从最终格子矩阵重新计算。

这套算法是可重复的工程基线，不代表已经比“今天拼豆了吗”或其他工具效果更好。当前已通过固定单元测试和自制示例转换；尚未完成30张图片盲评、真实用户评测和实物拼制。

## 4. 色卡与购买清单状态

当前应用只使用 `Demo 56 色测试色卡`，色号是 D001–D056 的自定义测试编号，不是 MARD、Perler、COCO 或其他零售色号。界面、图纸、PDF、CSV均明确提示“非零售色号、购买对应未核验”。

当前可以输出：

- 图纸实际使用色号与每色数量。
- 总豆数、实际颜色数。
- 用户填写备损百分比后的建议准备数量。
- 用户填写每包颗数后的建议包数。

当前不能承诺：淘宝/京东/拼多多商品SKU、实时价格、库存、店铺对应或“按清单一定买对”。正式采用某个品牌色卡前，必须取得来源和许可，建立品牌/系列/版本/色号/商品规格/核验日期映射，并进行实物抽样。

## 5. 交互逻辑

### 未上传

- 单一主按钮“选择图片”，也支持桌面拖放；不展示一堆无效灰色工具。
- 提供一张自制示例，方便不上传个人照片就验证流程。

### 已上传

- 预览原图和裁剪结果。
- 基础参数：照片/插画或像素画、长边格数、最大颜色数、测试色卡。
- 高级项默认折叠：抖动、去杂点、豆径、透明阈值、衬底。
- 生成前不显示假进度；生成中可取消，旧结果保持。

### 已生成

- 画布可切换纯色预览/网格/色号，原图对比保持同一裁剪。
- 基础工具：移动、画笔、擦除、取色、撤销/重做；支持手机双指缩放和+/-/适应按钮。
- 用量列表点击可高亮色号；全局换色需确认，修改可撤销。
- 参数修改后显示“新设置尚未应用”；重新生成前建立恢复点。
- 生成后的主按钮变为“下载图纸”。

### 输出

- PNG：预览或施工图，可选网格和色号。
- PDF：A4分区和独立材料用量页，嵌入中文字体。
- CSV：UTF-8 BOM，含图纸数量、备损、建议准备数量、可选包数和核验状态，并处理表格公式注入。
- JSON：包含色卡快照、算法版本、参数、矩阵，可重新打开。
