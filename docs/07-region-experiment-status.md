# 07 · 区域连贯实验路径：实现与不通过项

日期：2026-10-16。

## 结论

已增加独立实验路径和局部选区工具，但**没有得到可宣布为最优、或足以替换默认算法的证据**。默认保留原版，实验版需显式选择。

这不是“问题已修复”的验收报告。用户反馈的两张原始文件没有在本次受控浏览器环境中取得；本地草稿只恢复到之前自制小橘猫样例。未将截图裁出的小图冒充原图，也未上传私人图片。

## 1. 已实现

- 原版v1保持`convertBaseline`，无algorithm字段的旧项目按原流程解释。
- 实验版：中间图线性光采样、轻度/中度双边平滑、可选对比加权采样、实际色卡标签的边缘加权Potts/ICM局部优化（最多6轮）。
- “加强边界保护”降低强边缘两侧平滑，不是PixelOE形态学扩边。TS路径是独立启发式实验，不冒充PixelOE完整移植。
- 原生像素模式旁路纹理平滑/空间合色，保持最近邻采样。
- 默认实验路径拒绝抖动，避免与少碎点目标冲突。
- 点选相似色连通区域、增选/减选、清除/撤销选区、坐标选区。
- 选区内填当前颜色，跳过透明空格和保护格；图纸修改可撤销。
- 保护区与1–3色局部锁色。锁色先占全局预算，保护细节需要的候选色也占预算；超限明确报错。
- 保护和锁色重叠须先排除，不能悄悄覆盖五官。
- 约束绑定格数/裁剪/旋转。几何变化后不套旧mask；原版和实验版切换不重解释已生成图纸。
- JSON严格校验约束，旧项目不带新增字段仍可打开；本机草稿保存约束，支持独立约束撤销。
- 同参数对照：相同原图、裁剪、格数、最大色数、色卡；均关闭抖动和旧cleanup，不套人工约束，不覆盖作品。

## 2. 实际对照结果：不能判实验版获胜

`tests/research-benchmark.test.ts` 生成固定的96×96自制输入：渐变脸、两处深色眼睛、细纹衣服。输出48×48、最多12色、相同Demo56。

| 指标 | 原版 | 区域实验版 |
|---|---:|---:|
| 小连通块（<=3格，整图） | 2 | 18 |
| 指定眼睛检查位置仍为深色 | 2/2 | 2/2 |

实验版内部ICM从19块降至18块；**内部减少不能证明比原版好，横向比较实际仍多于原版**。从预览可见部分新增小块位于眼睛及其边缘，不应机械地视为全是噪点；但这仍不足以证明衣物质量或总体可辨识度改善。

同一输入的本机单次运行：原版约4–10ms，实验版约150–400ms。单元测试并行/预热会影响时间，这些不是手机性能承诺。

## 4. 仍未解决

1. 自动识别脸、衣服、眼睛；当前没有语义模型。
2. 保证任意32格照片五官可辨；保护选区也不能创造分辨率不足时不存在的信息。
3. 保证平坦区域和重要图案总能正确区分；平滑参数仍可能产生取舍。
4. Demo56不是零售色卡，不能照单购买；更丰富合法色卡需单独核验并独立对照，不能用换色卡掩盖算法变化。
5. 精细特征保护、面积采样与色卡候选选择的进一步联合优化。

## 5. 当前使用方式

1. 上传图片后，先用“同参数前后对比”比较，不必覆盖已有作品。
2. 在“转换算法”中显式选“区域连贯·实验版”，再调整轻/中去纹理与连贯强度。
3. 需要明确同色号时：选区工具选底色，增选/减选排除五官，局部填色；或建立1–3色约束后重新生成。
4. 先保护五官再锁底色；保护和锁色不得重叠。更改尺寸/裁剪后重新选区。

**验收决定：保留实验版供对照和局部操作，不切换默认，不宣传效果领先。**
