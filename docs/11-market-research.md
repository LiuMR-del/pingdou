## 1. 摘要

1. **市场真实且高速膨胀**：2025 年主流电商拼豆销售额 2.91 亿元、同比 +896%；机构预测 2026 逼近 10 亿元；淘宝搜索量同比近 +500%；小红书「我染上了拼豆」话题浏览超 36 亿次。
2. **工具赛道已高度拥挤**：免费 Web、会员订阅 App、开源项目、小程序四类并存，且多数已内置 MARD/COCO/Artkal 色卡与本地处理。**"照片转图纸"本身不再是差异化**。
3. **变现主流是会员订阅 + 材料包导流**；单次导出付费在海外已验证（stitchmate $7.99）；**"图纸生成器给线下拼豆店做 SaaS"未见成熟案例（D 级空白点）**。
4. **线下门店是隐藏 B 端**：单店月流水 15 万、净利 7.2 万的案例存在，门店现场需要帮客出图纸，但未见批量采购工具的公开案例。
5. **最大风险是 IP 版权**（二次元形象转图纸）与**色卡数据授权边界无定论**；平台合规（备案/微信审核）暂无公开负面案例。
6. 对 pingdou 的含义：**不要靠"能转图"竞争**，要靠「真实可采购色号 + 版本保护/可复现的工程可信度 + 移动优先体验 + 本地隐私」组合，并优先考虑线下店 B 端空白。

## 3. 需求侧：玩家流程与"转换到什么程度算好"

### 3.1 社区公认流程（C 级，工具站教程高度一致）

选图 → 裁剪/调对比 → 定格数 → 定色数 → 转换 → **叠加原图对比还原度** → 手动精修 → 导出带色号+用量清单 → 备豆 → 分板拼制 → 熨烫 → 趁热压重物防变形。
被反复强调的三件事：**自动转图后一定要手动精修**；**追求高还原需手动校对初稿**；**核对色号是否与手中豆子同体系**。

### 3.2 参数习惯（口径分散，取交集）

- 格数：新手 20–32；均衡 48–64；头像 48–64、半身 64–80、肖像 100+；标准拼板 29×29，大图多板拼接。
- 色数：新手 3–8；常见 8–16；**"收敛到 12–24 种才好买豆"**；FunBead 教程原话："上限建议 24–72 色……超过 168 色太杂、拼时频繁换豆、成品显花；低于 24 色丢细节、人脸轮廓糊成一片。"
- 豆径：5mm 常规豆新手容错高；人像等细节要求高用 2.6mm 迷你豆但难度更高。
- 抖动：天空/肤色等渐变区建议开；图标/像素/游戏风建议关（边缘更干净）。开发者侧解释：抖动会产生大量 1×1 孤立格，需配合降噪/最小色块合并。

### 3.3 "好"与"翻车"的社区用词（C 级，含直接引文）

夸：**还原度高；颜色分层清楚不糊成一团；缩略图仍看清主体；图纸干净好认好做；格子对齐、移位概率下降**。
骂：**糊成一团；人脸轮廓糊成一片；碎色点/一堆杂色；成品显花；格数太少五官没地方放、再怎么调也救不回来；肤色偏色**。知乎软文概括三大痛点：**图纸模糊、色号对不上、算豆算到崩溃**。抖音/IG 侧原话："以前拼一张大图光对照图纸就要半小时，经常看错行全盘推翻，心态直接崩。"

### 3.4 照片要求（C 级）

好评底图：**主体清晰、背景简单、颜色统一**；"卡通风格、风景剪影、小物件转换效果最好"。
差评底图：模糊、复杂背景、多阴影、压缩噪点（"有点噪点就冒一堆杂色，人脸尤其严重"）、长宽比失衡（压扁/拉长）。建议"先裁成头像或半身，不要只靠加颜色补救"。

### 3.5 人工改图：普遍且必要（C 级）

优先改：**眼睛和面部特征、手/爪/道具、轮廓硬线、必须可读的文字**。实例手法：把零散黄橙杂点合并成两三种红；留 1–2 格白/浅粉做高光；轮廓用深色描一圈。工具：各站内置逐格编辑器；进阶先 AI 转像素画再转图纸。

### 3.6 备料与色差（C 级）

主色多备 **10–20% 余量**；**锁定单一品牌备豆**，缺货买小袋补充而非跨品牌近似替代；"屏幕有色差，优先看色号名称""色差以色卡为准，电子稿仅供参考"；豆子尺寸公差会导致熨烫后线条不直、表面不平。

### 3.7 可量化的"好"门槛（D 级推断，供产品验收参考）

结合社区口径与本项目 `docs/04` 指标，建议验收门槛：
1. 缩略到成品视觉尺寸（约 1:1 小图）下主体/五官仍可辨认；
2. 孤立单格（1×1 杂点）与 ≤3 格碎块设硬阈值（阈值需用真实玩家样例与盲测校准，当前未定）；
3. 用色落在 12–24 的"好买豆"区间，低用量色可合并；
4. 导出必带色号+颗数清单+分板线；
5. 转换耗时：中端手机 64 格/16 色 ≤3s（docs/04 预算）。
**注意**：社区未形成统一数值标准，以上为归纳推断；最终应以 ≥5 位新手盲测 + ≥3 份实物拼制记录校准（docs/04 要求，尚未执行）。

### 3.8 样例图集口径修正（2026-10-26）

原计划"自下载授权图片 + 本机算法转换"生成 100 对样例的做法**已废弃**：它只能证明算法自身输出，不能代表社区认可的"成功"标准。正确口径是收集玩家发帖的**"原图 → 成品图纸/实物"成功案例**（逐对取得转载授权，或只链接不存图），用于校准 §3.7 阈值与作为模板展示。该项待后续执行，不在本报告范围内。

## 5. 变现模式

1. **会员订阅/Pro 解锁**（主流）：趣拼豆、Resprite、pindou.online、pindou.baby。
2. **单次导出付费**（海外验证）：stitchmate $7.99+。
3. **材料包/门店导流**（有证据）：webfem 工具"匹配店家色号"引导至门店；淘宝 1–5 元"图纸生成/代做图纸"、29.8 元"看图配豆+材料包"定制热销；材料包与图纸绑定销售普遍。
4. **空白点（D 级）**：未见"图纸生成器作为线下店 SaaS/批量出图工具"的成熟案例。

## 6. 渠道与平台取舍

- **微信小程序是国内主要分发形态**（微信搜索即用、免下载）；小红书是种草主阵地（36 亿话题）；淘宝材料包页附赠/售卖图纸。
- 响应式 Web 的优势：免审核、无类目资质限制、跨端一套代码；劣势：国内发现性弱，依赖 SEO/知乎/技术周刊曝光（阮一峰周刊 #8918 收录拼豆生成器即为案例）。
- pingdou 现选择"只做响应式 Web、不做小程序"（docs/09）：与"缩短迭代周期"的目标一致，但**意味着放弃微信裂变主渠道**，获客必须靠内容/SEO/线下合作补。

## 8. 风险

1. **IP 版权（最高）**：夹娃娃机/毛绒玩具领域迪士尼、三丽鸥、玲娜贝儿侵权查处案例密集；拼豆图纸大量使用二次元 IP（拼豆大师直接宣传）。**尚无拼豆图纸工具被诉的公开案例（D 级）**，但工具若提供图库/社区 UGC，风险显著高于"仅本地转换用户自有照片"。pingdou 当前"不上传、不做图库/社区"的定位恰好规避了最大风险面，应保持。
2. **色卡数据授权**：社区已开源汇总（HansBug/pindou-color-data，MIT）；MARD 官方未见授权声明；商用色卡数据的授权边界无公开定论（详见色号调研报告 §8）。
3. **平台合规**：内地托管需 ICP 备案；微信内置浏览器导出/保存降级未验证（docs/04/09 自认）；暂无拼豆类小程序被拒审公开案例。
4. **品类生命周期**：媒体已警示网红品类同质化与退潮风险；2026-08 线下价格战是早期信号。

## 9. 对 pingdou 的定位建议（本次不实施）

1. **放弃"功能差异化"幻想**：转图+色号+导出是 commodity。竞争点改为：真实可采购色号（MARD 221 落地）+ 工程可信度（版本保护、恢复点、确定性可复现、诚实标注）+ 移动优先体验 + 本地隐私（不上传照片）。
2. **优先补两块 table-stakes**：真实色卡（见色号报告）；微信内置浏览器与真机导出降级验证。
3. **探索 B 端空白**：线下店"现场帮客出图"是真实高频场景且无成熟工具供给；可先以免费 Web + 门店色号映射试水，验证后再谈 SaaS。
4. **变现顺序建议**：先免费获客与口碑（本地隐私+诚实标注是稀缺信任资产）→ 材料包/门店导流佣金 → 高级功能订阅（大图分页、批量、云草稿）。**不要在色卡未核验前做任何"按清单买对"的承诺式收费**。
5. **验收先于扩张**：在执行完 docs/04 的 30 图盲评 + 5 新手 + 3 实物拼制之前，不投入图库/社区/商城，也不投放付费获客。
