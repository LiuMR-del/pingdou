# 01 · 产品范围与转换流程

日期：2026-10-15 · 状态：开发前建议基线

## 1. 本阶段目标

只做一件事：让电脑和手机用户，将自己的图片转换为清晰、可修改、可备料、可导出的拼豆图纸。

完成标准不是“生成了一张像素图”，而是：

1. 用户能理解格数、颜色数对细节和材料数量的影响。
2. 结果只使用所选色卡中有效的色号。
3. 图纸、统计清单和导出内容一致。
4. 不满意时能修改参数或局部修正，不丢失已有工作。
5. 手机端能完成完整流程，不要求转到电脑。

本阶段内按“基础转换 → 编辑与输出 → 跨端和质量打磨”迭代，不以尚未完成打磨为由启动图库等新模块。

## 2. 明确不做

- 找图、模板库、搜索、内容社区。
- 用户注册、付费会员、商城和材料交易。
- 库存管理、跨品牌实物等色承诺。
- AI 生成、生成式照片重绘、人脸/宠物特征增强。
- 截图网格识别、成品照片反推图纸、批量任务。
- 多图层、文字排版、3D 预览。

这些能力不放“敬请期待”入口，也不作为首页主导航。后续扩展只预留作品数据接口。

## 3. 功能分解

### 3.1 图片导入

- 支持 JPEG/JPG、PNG、WebP；导入 JSON 项目作为单独入口。
- 桌面：文件选择、拖入、粘贴剪贴板中的图片文件；无法粘贴时仍可选择文件。
- 手机：系统图片选择器，不默认强制相机，不要求登录。
- 不支持远程 URL 图片导入，避免跨域、隐私和不可信资源问题。
- GIF、SVG、HEIC 暂不支持，提示用户转为受支持格式；iPhone 实际选图兼容性必须真机验证，不能假定浏览器一定自动转码。
- 建议初始上限：单文件 20 MB、解码前可检查到的尺寸不超过 40 MP；解码前后都检查，极端图片拒绝或提示缩小。该上限须根据手机内存实测下调。
- 解码后立即按处理需求降采样，及时释放原始位图引用；大图不反复完整解码。
- 尊重 EXIF 方向；基础版本按浏览器解码的 sRGB 工作流处理，不承诺专业色彩管理。
- 项目文件不包含 EXIF 元数据；基础版本只保存必要的降采样图片、参数和图纸。

### 3.2 裁剪与图像准备

- 自由、原比例、1:1 比例裁剪；默认保留原比例，不暗中居中裁掉主体。
- 90° 旋转、水平/垂直翻转；执行后预览对应的实际结果。
- 裁剪框支持拖动，同时提供位置/宽高调整或方向按钮替代，不能只靠拖动。
- 保留源图，裁剪可重新调整，不破坏源图。
- 第一版不做自动抠图。透明 PNG 可直接保留；编辑器可手工擦除不需要区域。
- 透明度按固定且记录在参数中的规则映射为空格；基础版阈值默认 128/255。
- 半透明像素先按选定衬底合成后再映射，避免透明边缘变黑；提供白色衬底默认值和颜色选择。
- 不提供容易被误解的“一键背景色全删除”：背景与主体同色可能被一并删除。

### 3.3 转换设置

#### 基础设置：默认展开

1. 图纸尺寸：长边 16–128 格，快捷项 32 / 48 / 64 / 96；默认 48 格，作为待验证基线。
2. 比例：默认锁定，显示计算后的宽 × 高；展开可自定义宽高，每边 8–128，单次最多 16,384 格。
3. 最大颜色数：4–32，快捷项 8 / 12 / 16 / 24，默认 16。实际可用颜色可能少于上限，清楚显示“实际使用 N 色”。
4. 品牌色卡：首次只发布一套经过来源与数据校验的明确版本，例如 MARD 221；未核验数据前只在开发环境使用测试色卡，不声称能采购到对应实物。
5. 豆子规格：2.6 mm / 5 mm / 自定义中心间距。该设置影响尺寸估算，不代表不同直径可以混用。

#### 高级设置：默认折叠

- 抖动：默认关闭；开启后显示“渐变更丰富，也可能增加零散色点”。
- 去杂点：默认关闭，开启后支持低/中两个强度；结果应可对比，不自动删除所有单格，因为眼睛、高光可能就是单格。
- 对比度、饱和度：可后置到打磨阶段，不阻断首个转换闭环。
- 透明阈值和衬底设置。

#### 成品尺寸估算

优先使用色卡/底板对应的实际中心间距 p 和豆体直径 d。外形宽约为 (列数 - 1) × p + d；高度同理。若只知道标称豆径，显示“粗略估算，未含底板间距、熨烫变形及收缩”，不得使用精确到毫米的承诺式表述。

### 3.4 转换管线

建议基线：

1. 解码、方向归一、裁剪、透明处理。
2. 根据目标格数，对对应原图区域采样；不得拿浏览器 CSS 缩放截图代替算法。
3. 感知空间内限色与色卡匹配，比较 CIEDE2000 和较快近似实现；优先保证确定性和结果一致性。
4. 色卡内颜色预算优化，避免“先任意量化再就近映射”产生大量重复色；如有重复则合并并重新统计。
5. 根据设置应用抖动/去杂点，再确保每格色号属于当前色卡。
6. 输出格子矩阵、色卡版本、颜色统计和转换参数。

不宣称该管线一定领先；以固定输入的基线对比和用户盲评判断。长任务使用 Web Worker，旧请求不能覆盖新请求。

### 3.5 预览与基础微调

- 默认展示生成结果，原图可切换；桌面大屏可选并排对比。
- 视图：预览 / 网格 / 色号；手机色号只在格子足够大时绘制，缩小时提示放大查看。
- 缩放、适应画布、100%、坐标定位。
- 画笔、橡皮擦、取色、移动；全局颜色替换。
- 撤销/重做：至少保留最近 50 个编辑操作，连续一次笔划算一步；缓存采用差量，不为每次操作复制原图。
- 擦除结果为空格，不是白色豆子；透明空格、白色豆子必须区别显示。
- 色卡外颜色禁止直接绘入，所有改色都落在当前色卡。
- 每次编辑同步更新实际颜色数和豆数。
- 操作日志只属于当前图纸版本；重新生成新版本后建立新的编辑历史，旧版本有备份。

### 3.6 色号与用量

- 显示色块、品牌色号、颜色名（如数据有）、数量和占比。
- 可按色号/用量排序；默认用量降序。
- 点击色号可高亮对应格子，提供“退出高亮”。
- 替换颜色需明确源色和目标色，展示将影响多少格；确认后可撤销。
- 区分总格数与总豆数：空白透明格不计入豆数。
- 不把显示器色块当作实物准确颜色证明；显示“屏幕、实物和批次可能有色差”。

### 3.7 导出

统一入口：“下载图纸”，打开导出面板。

- PNG：清晰预览 / 带网格施工图 / 带色号施工图；图例和用量可勾选。
- PDF：A4 页面，标题、色卡版本、宽高格数、网格、图例、总豆数；大图支持多页和定位重叠。
- CSV：UTF-8 BOM，品牌、色卡版本、色号、颜色名、数量；转义逗号/换行，防表格公式注入。
- 项目 JSON：数据版本、图纸矩阵、参数、色卡引用及必要快照，可再次打开；包含降采样图片时需提示。
- 文件名建议：作品名_48x48_MARD221_图纸.png；清理不合法字符。
- 施工图不声称可直接将底板放在屏幕上 1:1 对位。PDF 若提供实物比例，必须有校准尺，并要求打印时选择实际大小后测量校准；默认按可读性分页。
- 高分辨率导出设像素总量限制，超限引导 PDF 分页；手机不可创建极大单张 Canvas。
- 生成中或失败状态不能把旧结果冒充当前参数结果导出。
- 手机优先文件下载，可在支持时调用系统文件分享；Safari/微信失败时提供打开图像后保存和外部浏览器提示。

### 3.8 本地草稿

- 默认一个“最近作品”草稿，使用 IndexedDB 存图纸/必要图片，不把大图塞进 localStorage。
- 编辑后约 1 秒防抖保存；显示保存中/已保存到本机/保存失败。
- 恢复时显示缩略图和保存时间，由用户选择继续或新建。
- 本机不等于云端；无痕模式、存储配额、系统清理可能导致丢失。
- 提供项目文件下载作为备份；保存失败不阻止当前编辑或导出。

## 4. 状态与版本规则

| 状态 | 主操作 | 关键规则 |
|---|---|---|
| 未选图 | 选择图片 | 不展示大片无意义禁用按钮 |
| 已选图待生成 | 生成图纸 | 显示裁剪后的源图与基础参数 |
| 生成中 | 取消生成 | 保留当前画布，显示真实阶段；不编造百分比 |
| 生成成功 | 下载图纸 | 同时可继续编辑，顶部显示版本摘要 |
| 参数已变更 | 应用并重新生成 | 旧结果加“尚未应用新设置”提示，下载需明确“上次结果”或先应用 |
| 有人工修改且需重生成 | 确认重新生成 | 先创建本地恢复点；明确新生成会替换当前图纸，旧编辑不自动迁移 |
| 生成失败 | 重试生成 | 保留图片、参数和上一份有效结果，不清空工作 |
| 导出中 | 正在导出 | 防重复点击，其他可安全操作按实现限定 |

确认弹窗按钮：次按钮“保留当前图纸”，主按钮“备份并重新生成”。备份失败时不得假装已备份，提供先下载项目或明确放弃当前编辑的选择。

## 5. 最小作品模型

- schemaVersion、作品 ID、标题、创建/修改时间。
- source：降采样原图引用、尺寸、裁剪和旋转信息；清除时删除本地对象引用与持久化数据。
- settings：尺寸、颜色上限、透明规则、抖动、色卡 ID/版本、算法版本。
- generatedSettings：当前有效图纸实际对应的参数，不能仅有正在编辑的表单值。
- grid：宽高与每格色号索引，空格使用独立哨兵值。
- paletteSnapshot：当前作品所用色号、显示颜色、数据来源/版本。
- statistics：从 grid 派生，导入后重新计算，不信任文件携带统计。
- revision：生成版本、人工修改标记、恢复点。
- view：缩放、视图类型等可选信息，不影响导出内容。

导入项目验证尺寸、格子长度、索引范围、字段长度、版本和文件大小；不执行任意内容，不信任自带 SVG/HTML。
