# 国内优先与有限选色修正评估

日期：2026-10-20。

## 1. 产品范围

当前阶段先服务国内用户，保留电脑和手机共用的响应式 Web。不开小程序、不做出海 SEO、找图、社区或商城。

理由是缩短当前开发与迭代周期，而不是断言 Web 在所有国内渠道都更优。电脑端适合精确编辑、打印导出；手机端适合选图、预览和轻微修改。现有转换核心继续与平台分离，未来确有微信内分享、回访、保存或制作进度需求，再单独评估小程序的 Canvas、Worker、文件导出、包体及真机适配成本。

尚未验证微信内置浏览器、iOS Safari、Android 真机的完整导出流程。正式部署时，根据服务器/CDN所在地确认域名、HTTPS、备案及个人信息处理要求；中国内地托管通常需要相应备案。不能把“海外托管”理解为免除其他合规责任。本轮没有部署或接入支付。

## 2. 本轮候选与隔离范围

原版 `linear-area-lab-kmeans12-ciede2000-v1`、默认配置和历史项目含义保持不变。没有添加用户选项。

新候选只在 `scripts/research/palette-refinement.ts` 由研究测试调用：

- 完全复用 baseline 的采样、直方图、聚类及最终映射。
- 枚举当前色卡中全部未选色号作为替换候选。最初按计划只取各点最近色号，复核发现会漏掉对多个点更优的折中色，已修正为完整色卡搜索，并增加中性Lab反例测试；仍只执行一次替换，不求全局最优色板。
- 缓存 CIEDE2000 距离、当前最近及次近误差，最多替换一个已选色号。
- 只接受严格降低“加权直方图点到所选色板最小 CIEDE2000 总和”的替换；同分保留固定先后顺序，无收益不换。
- 颜色数不增加，不改变透明判定，不混用抖动、cleanup或人工约束。

这不是空间一致性算法，也不是语义识别。直方图平均点的目标改善不保证逐格真实误差、区域连贯或用户观感改善。

为复用既有代码，`src/core/convert.ts` 抽出可选选色修正回调。生产 `convertBaseline` 不提供回调；正式分派仍只有 baseline/region。改动前已生成7组固定输入的格子SHA-256摘要，改动后逐组一致。快照不由常规测试自动更新。

## 3. 样本与比较条件

共3个项目自制样本 × 32/48/64格 × 8/16色，共18组；固定 Demo56 的完整数据及颜色顺序，关闭抖动和cleanup，无人工约束。

- gradient：原有96×96确定性渐变脸、眼睛、细嘴和衣纹样本，抽为共享fixture。
- texture：沿用此前自制256×256卡通纹理原图，没有截图裁图或网络图片。
- cat-redrawn：依据 `src/image.ts` 猫图几何用Pillow重绘并超采样。**不是浏览器Canvas原输出，抗锯齿和路径栅格化可能不同**，不能把结果当作同一猫图的跨轮数值回归。

没有读取私人草稿，没有上传图片，没有授权真人照片或真实玩偶照片，因此本轮只能筛选机制，不能验收照片转换质量。

## 4. 实际结果：不通过，不启用默认

**18组中7组发生变化；所有16色的9组完全无变化。**

| 样本 | 变化的条件 | 目标误差下降 | 关键观察 |
|---|---|---:|---|
| gradient | 64格/8色 | 约0.09% | 眼睛边缘颜色变化，衣物选定区域碎点未减少；其余5组不变 |
| texture | 32/48/64格的8色 | 约0.37%–0.70% | 32/48格脸部出现更明显的两色分界；纹理ROI碎点均未下降；32/48格眼睛仍然很弱 |
| cat-redrawn | 32/48/64格的8色 | 约0.04%–0.17% | 48格双眼ROI中L*<50的格数从5/4降至3/3；不能认定细节保留更优 |

已读取并检查三张实际无网格预览对照。texture中更明显的脸部色块分界直接说明：全图色差目标可能以牺牲局部连贯为代价，不能只凭数值下降切换算法。

选定纹理/平涂ROI的小连通块数量在所有18组中都未下降。这里ROI比较并非整件衣服的完整分割，不能泛化为所有区域、所有照片都没有变化。

### 性能

每组预热后交替运行原版与候选各7次，取各自中位数。完整色卡搜索的最终批次：原版约0.87–9.51ms，候选约0.97–11.56ms；18组相对比值中位约1.21倍，范围约0.86–1.69倍。小于1的比值体现短时测量抖动，不能解释为新增计算反而更快。是本机Node中一次研究批次，不含浏览器解码、Worker传输或手机性能，不作体验保证。

虽然绝对额外耗时较小，但没有稳定视觉收益，仍不值得进入默认产品路径。

### 指标局限

- 双眼及嘴部按已知几何ROI统计深色格、亮度和相对脸区最暗对比；不是检测器，不是五官召回率，也不能用于真实照片识别。
- 单个L*阈值会漏掉浅色但可辨认的嘴，黑格增加也不一定是进步；必须看预览。
- 外轮廓/透明正确性有专用回归，不能以本轮全不透明预览宣称轮廓和透明照片已通过视觉验收。
- 颜色预算不代表实际必须用满；候选只替换，不加色，不能弥补Demo56缺少合适肤色的问题。

**结论：保留研究实现和失败样本，拒绝晋升默认。用户界面、操作步骤及实际默认结果没有改变。**

## 6. 后续边界

不因本次失败立刻叠加更多参数、换更大色卡或要求用户手工保护来宣布修复。真正照片质量验收仍需要明确授权的原始照片和同条件比较。国内真实零售色卡的核验是独立任务，不能把换色卡收益混成算法收益。当前Demo56仍不可直接用于采购。
