## 2. 竞品记录

### 2.1 PixelBeads（pixelbeads.io）

来源：https://www.pixelbeads.io/zh-cn/perler-bead-pattern-maker

#### 实际观察（A）

1280×720 桌面首屏：
- 暖白背景、白面板、黑色主按钮。
- 顶部导航和大标题说明占用较多高度。
- 工作区同时排列原图、图纸、参数；画布展示空间分散。
- 网格输入和32/64/96快捷项清晰。
- 大量颜色数档位在参数区铺开。

390×844 窄视口首屏：
- 导航改为折叠菜单，整体无明显水平溢出。
- 上传入口可见，但其上方保留了较高说明区。
- 参数在上传后纵向排列；本次首屏底部已经到色盘附近，而生成按钮与预览不在该首屏中。
- 这一观察说明首屏可达性可以优化，不能据此断言整个网站手机不可用。

DOM 可见控件：
- 原图/结果比较、网格20–128、颜色数、MARD/COCO/Perler/Hama、个人色盘、编辑器、导出。
- “生成后自动打开编辑器（仅电脑）”选项，说明竞品存在跨端编辑流程差异。
- 上传前已存在多种禁用操作。

截图仅保存在本地，未随公开仓库发布：
- 桌面1280×720：`docs/assets/pixelbeads-desktop.png`。
- 窄视口390×844：`docs/assets/pixelbeads-mobile.png`。

截图仅用于内部研究，版权归对应网站；不得直接用于本产品对外宣传。

#### 本产品采纳（C）

- 采纳：明确格数预设、色卡名称、颜色用量、生成后可修正。
- 不照搬：大量操作和参数一屏并列、未上传就展示许多禁用按钮。
- 改进：工具首屏、单主画布、手机预览优先、参数底部面板、编辑不自动跳新页面。

## 3. 规范参考

### 3.1 目标大小

WCAG 2.2，SC 2.5.8，AA：一般最小目标24×24 CSS px，带间距、等价控件、行内等例外。

来源：https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html

本产品采用更宽裕的44–48px按钮命中目标，是产品设计决定，不把它写成该AA条款要求。

### 3.2 文字对比度

WCAG SC 1.4.3，AA：普通文字至少4.5:1；大文字至少3:1，大文字定义为至少18pt或14pt加粗。

来源：https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html

候选设计颜色已计算部分配对，详见界面设计规范；并不等于整站通过WCAG。

### 3.3 拖动替代

WCAG 2.2，SC 2.5.7，AA：除必要拖动或未修改的用户代理行为等例外，应提供无需拖动的单指操作替代。只有键盘路径不一定满足单指替代要求。

来源：https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements.html

应用：裁剪可用数字/按钮调整，缩放有+/-，滑块有数字输入，底部面板有关闭按钮，不把拖拽、双指、下滑作为唯一入口。

## 4. 从研究得到的设计决定

| 观察或约束 | 本产品设计决定 | 后续验证 |
|---|---|---|
| 窄视口纵向参数让预览/生成离开首屏 | 手机预览优先，设置放底部面板 | 真机观察新手能否找到生成 |
| 原图与结果并排压缩各自面积 | 默认单画布切换，桌面可选并排 | 比较任务是否易完成 |
| 专业编辑器工具多 | 本阶段仅画笔/擦除/取色/移动/全局换色 | 是否足够修正常见结果 |
| 实物颜色受品牌/版本/屏幕影响 | 展示色卡版本、色号和色差提示 | 色卡数据核验，实物小样比对 |
| 手机操作可能误画 | 浏览默认移动，微调显式进入，双指防误画 | 手指实际操作测试 |
| 重新生成可能丢人工编辑 | 有效结果与待应用参数分离，创建恢复点 | 多种失败/取消场景测试 |
| 本地存储可能被系统清理 | 本机保存状态+项目文件备份 | iOS配额、无痕与失败测试 |
