# 拼豆图片转换工具

当前阶段只开发和打磨“图片 → 拼豆图纸”，不启动图库、社区、商城、库存管理等新模块。

当前已实现一个可运行的转换工作台原型：上传/示例、裁剪、浏览器本地转换、画布微调、用量与备料清单、PNG/PDF/CSV/JSON导出和本机草稿。正式色卡和零售购买映射尚未核验，当前界面使用明确标记的 Demo 56 色测试色卡。

完整实施状态见 [实施方案与当前状态](docs/05-implementation-plan.md)。

**算法质量尚未验收通过。** 用户反馈照片碎点和五官损失后，已增加“区域连贯·实验版”、局部选区合色/保护及同参数对照。尚无结果证明实验版整体优于原版，因此未替换默认。详见 [研究与PixelOE实际实验](docs/06-algorithm-research.md) 和 [区域实验结果与失败项](docs/07-region-experiment-status.md)。

## 核心设计决定

- 视觉方向：轻手作感、工具级可读性。暖白外壳、青绿色主操作、中性画布，不使用满屏糖果色或像素字体正文。
- 桌面端：大画布 + 右侧参数面板；默认单预览，可切换原图对比，不强制双画布。
- 手机端：预览优先 + 底部设置面板 + 固定主操作，不把桌面侧栏简单堆成长页面。
- 流程：选择图片 → 生成 → 浏览结果 → 下载；裁剪、参数修改和微调按需进入。
- 平台：现阶段国内优先，只维护电脑与手机响应式 Web，不同时开发小程序或出海 SEO。
- 功能：常见图片格式、裁剪、尺寸与限色、明确版本的色卡、基础编辑、用量统计、PNG/PDF/CSV/项目文件、本地草稿。
- 质量：参数修改不直接覆盖已有图纸；重新生成前保护人工修改；导出始终对应一个明确的已生成版本。
- 隐私：基础转换默认浏览器本地处理；未实现、未验证前不宣传“AI”“最佳颜色还原”“库存适配”等能力。

## 本地运行

```bash
npm install
npm run dev
```

然后打开 Vite 输出的本地地址（通常是 `http://127.0.0.1:5173/`）。

```bash
npm run typecheck
npm test
npm run build
```
